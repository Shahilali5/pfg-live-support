INTEGRATION IN 30 SECONDS

Embed Anywhere With A Single Script Tag

Works seamlessly across React, Next.js, Vue, WordPress, Shopify, PHP, and static HTML. Zero CSS conflicts with host websites.

HTML Embed Snippet 
<!-- Place this single script tag right before your closing </body> tag -->
<script
  src="http://localhost:3000/widget.js"
  data-site-id="pfg_gateway_default"
  async>
</script>

HTML Data Attributes (Zero-Config or Fully Customized)

Attribute Required Default Description
src Required - Absolute URL to your hosted widget.js endpoint.
data-site-id Optional pfg_gateway_default Tenant or website identifier for multi-site routing and separation.
data-company-name Optional PFG Support Overrides widget header company / brand title.
data-primary-color Optional #4F46E5 Primary brand theme hex color for floating launcher and customer bubbles.
data-position Optional right Screen placement: right (bottom right) or left (bottom left).
